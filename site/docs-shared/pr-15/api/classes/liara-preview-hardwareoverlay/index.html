              liara::preview::HardwareOverlay

              structinclude/sample.hpp

              A low-level hardware or packet configuration overlay.

              Exercises how a plain struct and an anonymous union render within the Liara Engine design system.

              struct HardwareOverlay {
    std::uint32_t id;
    union {
        std::uint32_t raw_flags;
        struct {
            bool is_active :1;
            bool has_error :1;
        } bits;
    } status;
};
