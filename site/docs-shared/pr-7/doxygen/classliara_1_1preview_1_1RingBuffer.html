Detailed Description

template<typename T, std::size_t Capacity>
class liara::preview::RingBuffer< T, Capacity >

A fixed-capacity ring buffer.

Template Parameters
TElement type. Must be trivially copyable.
CapacityMaximum number of live elements.
Note
This type performs no heap allocation.
Warning
Pushing into a full buffer overwrites the oldest element.
