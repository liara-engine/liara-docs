              functiondispatch_command#

              bool liara::preview::dispatch_command(std::uint32_t channel_id, std::span< const std::byte > payload)

              Dispatches a transactional command payload to the engine core.

              This heavy synthetic function is explicitly designed to stress-test every single customized admonition box, parameter layout, exception table, and return-value block defined inside doxygen-custom.css.

              Attention

              High frequency calls to this function can incur hardware bus lockups.

              Bug

              Context switching timings are unstable under highly nested interrupts.

              Todo

              Implement hardware fallback queues before the next preview release.

              Precondition

              The engine subsystem must be initialized via liara::core::init().

              Postcondition

              The targeted channel will transition to a busy state until flushed.

              Thread Safety

              This function is thread-safe and can be invoked from concurrent context pipelines.

              See also

              to_string

              Parameters

              NameTypeDescription
              channel_idstd::uint32_tThe destination pipeline index. Must be strictly less than MaxChannels.
              payloadstd::span< const std::byte >A view over the raw byte sequence to transmit.

              Returns

              bool

              ValueMeaning
              trueThe transaction was successfully committed and processed.
              falseThe command was rejected because the channel is currently choked.

              ExceptionWhen
