One frame's worth of drawable data, extracted by the core and submitted to the renderer.

Thread Safety
This type has no thread-safety concerns of its own; it is plain data. The lifetime of the drawables pointer is documented by whichever function produces the packet (see liara_core_get_render_packet).
Parameters
-Version of this structure. See LIARA_RENDER_PACKET_VERSION. Width of the render target, in grid cells. Height of the render target, in grid cells. Color used for cells with no drawable, 0xAARRGGBB. Caller-owned array of drawables; see the note above. Number of entries in drawables.
