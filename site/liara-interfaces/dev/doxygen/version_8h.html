Create a version number from major, minor, and patch components, with NO safety checks.

This macro combines the major, minor, and patch version numbers into a single 32-bit unsigned integer.

Warning
This macro does not perform any safety checks on the input values. It is the caller's responsibility to ensure that the major, minor, and patch values are within their respective valid ranges:
  • major must be between 0 and 1023 (inclusive)
  • minor must be between 0 and 1023 (inclusive)
  • patch must be between 0 and 4095 (inclusive)
Parameters
[in]majorThe major version number (0-1023).
[in]minorThe minor version number (0-1023).
[in]patchThe patch version number (0-4095).
Returns
A 32-bit unsigned integer representing the combined version.

This macro is thread-safe as it does not modify any shared state.

Inline function to create a version number from major, minor, and patch components.

This function combines the major, minor, and patch version numbers into a single 32-bit unsigned integer. It performs safety checks to ensure that the input values are within their respective valid ranges:

  • major must be between 0 and 1023 (inclusive)
  • minor must be between 0 and 1023 (inclusive)
  • patch must be between 0 and 4095 (inclusive)

If the input values are valid, the combined version is stored in the output parameter out_version. If any of the input values are out of range or if out_version is NULL, the function returns an appropriate liara_result error code and does not modify out_version.

The allocation of the output parameter is the responsibility of the caller, and it must be a valid pointer to a uint32_t.

Parameters
[in]majorThe major version number (0-1023).
[in]minorThe minor version number (0-1023).
[in]patchThe patch version number (0-4095).
[out]out_versionPointer to a uint32_t where the combined version will be stored if successful.
Returns
LIARA_RESULT_SUCCESS if the version was successfully created and stored in out_version, LIARA_RESULT_NULL_POINTER if out_version is NULL, LIARA_RESULT_OUT_OF_RANGE if any of the input values are out of range.
Thread Safety
This function is thread-safe as it does not modify any shared state.
