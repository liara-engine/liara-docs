Liara Engine

A modern 3D game engine, built from scratch in C++ with Vulkan, as a personal learning project. Modular by construction, cross-platform, and openly developed.

Read the user guide View on GitHub
  • License MIT
  • Language C++20 / C ABI
  • Graphics Vulkan 1.3
  • Platforms Linux, Windows

Modules

Liara is composed of independently versioned modules connected through a stable C ABI. Each has its own repository and its own API documentation.
