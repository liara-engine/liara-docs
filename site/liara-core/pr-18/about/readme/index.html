    liara-core

    Section titled “liara-core”

    The core library for the Liara Engine.

    This repository contains the c++ implementation of the Liara Engine’s core module. It is a consumer of the Liara Interfaces.

    This module provides the foundational components and abstractions for the Liara Engine, including memory management, logging, configuration, and other essential utilities.

    Status

    Section titled “Status”

    Phase 0 — bootstrap. The core library is in the early stages of development, and the API is subject to change.
